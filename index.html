Resumen de la página

Esta página web fue creada utilizando HTML y CSS. El HTML se utilizó para estructurar el contenido mediante etiquetas como div, h1, h2, p, ul, li, table e img. Cada sección de la página está agrupada con la etiqueta div para organizar mejor el contenido.

Los estilos visuales se aplicaron utilizando CSS, donde se definieron colores, espaciados, bordes, tamaño de imagen y tipo de letra para mejorar la apariencia de la página. También se utilizó la etiqueta span para resaltar texto importante con color rojo y negritas.
